# Economy

## Two economies, intentionally

The game economy and any future network economy are separate systems.

### Game economy

- Cash — idle operation progression.
- Scrap — crafting/upgrades.
- Carrots — energy/event/cosmetic design space.
- Medals — rank/progression.
- Bomb parts/blueprints — equipment unlocks.

These are game balances first. They do not need to be blockchain assets and should not be NFTs by default.

### Protocol economy

v0 has **no transferable protocol token**.

Proof of Play should first demonstrate that attested participation, reputation, committees, and finality can resist attacks. Only then evaluate whether a token is required for incentives, spam resistance, fees, or governance.

## Design constraints

- Never promise players passive financial returns for leaving the game open.
- Avoid making ordinary progression depend on speculative asset prices.
- Do not tokenize every inventory item.
- Keep skill matchmaking and combat power insulated from wallet size.
- Real-money tournament/pool mechanics require dedicated legal/product review before implementation.

## Candidate future sinks

If a protocol asset eventually exists, safer initial uses to research include network fees, creator publishing bonds, anti-spam deposits, or protocol governance. None are committed designs.
